# SSEVM — Self-Sustainable Eco-Village Model

Off-grid community villages built on faith, health and learning — Madinah, Brunei, Aceh and more.

Bismillah. This repository is the shared model: one plan and one structure that every SSEVM
village follows. Each location will get its own repository with the same layout.

## The two focus areas

1. **Self-sustainable village**: homes, masjid, madrasah, clinic, community hall, food, water,
   how the village is run, money, and the build phases.
2. **Off-grid living**: solar energy and batteries, rain and bore water, composting toilets and
   grey water, food growing, low-cost building methods, and the site layout.

**Health comes first**: the village health plan is built around the MSA Health app.
**Learning**: the madrasah uses the Madrasah Study App (MSA).

## Where things are
